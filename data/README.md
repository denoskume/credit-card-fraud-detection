# Dataset

This project uses the public **Credit Card Fraud Detection** dataset released through the Machine Learning Group at Université Libre de Bruxelles (ULB), based on European card transactions.

## Expected local file

Place the downloaded CSV here:

```text
data/creditcard.csv
```

The raw CSV is intentionally excluded from version control.

## Expected schema

- `Time`
- `V1` to `V28`
- `Amount`
- `Class`

`Class = 1` denotes fraud and `Class = 0` denotes a legitimate transaction.

Dataset page: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
